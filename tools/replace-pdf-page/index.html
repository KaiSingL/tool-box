Replace PDF Page

Replace one page in a PDF with a page from another PDF. Runs entirely in your browser.

1. Choose files

The document that contains the page you want to replace.
The PDF that holds the new page. It can have one page or many.

2. Choose pages

Load the combined PDF first.
Load the replacement PDF first.
Select both files to see the swap plan.

3. Build the new file

Output name: original name + -pageN-replaced.pdf. Source files are not overwritten.

How it works

  1. Load both PDFs in the browser with pdf-lib.
  2. Copy every original page except the one you chose to replace.
  3. Insert the chosen replacement page in that same position.
  4. Save a new PDF and trigger a download.

Password-protected files may fail. Mixed paper sizes usually work. Bookmarks and form fields on the replaced page are dropped with that page.
